## Changes Made

### 1. `frontend/src/api/client.js` - Added Settings API Methods

**Lines modified:** ~275-295

Added four new methods to the `RAGAPIClient` class:
- `getSettings()` - Retrieves all settings from `/settings` endpoint
- `getCategorySettings(category)` - Gets settings for a specific category
- `updateSetting(category, key, value)` - Updates a single setting via PUT
- `resetSettings()` - Resets all settings to defaults via POST
