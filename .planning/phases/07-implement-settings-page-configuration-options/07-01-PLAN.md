<task type="auto">
  <name>Add Settings API Endpoints</name>
  <files>src/main.py</files>
  <action>
    Add to `src/main.py` after existing stats endpoints:

    ```python
    # Settings Models
    class SettingsUpdateRequest(BaseModel):
        category: str  # api, cache, rate_limiting, ui_preferences
        key: str
        value: Any

    # Settings Endpoints
    @app.get("/settings")
    async def get_settings():
        """Get all current settings"""
        return get_settings()

    @app.get("/settings/{category}")
    async def get_category_settings(category: str):
        """Get settings for a specific category"""
        settings = get_settings()
        if hasattr(settings, category):
            return {category: getattr(settings, category)}
        raise HTTPException(status_code=404, detail="Category not found")

    @app.put("/settings")
    async def update_setting(request: SettingsUpdateRequest):
        """Update a specific setting"""
        success = update_setting(request.category, request.key, request.value)
        if success:
            return {"status": "updated", "category": request.category, "key": request.key}
        raise HTTPException(status_code=400, detail="Failed to update setting")

    @app.post("/settings/reset")
    async def reset_settings():
        """Reset all settings to defaults"""
        reset_to_defaults()
        return {"status": "reset"}
    ```

    Import necessary types: `Any` from typing, `HTTPException` from fastapi
  </action>
