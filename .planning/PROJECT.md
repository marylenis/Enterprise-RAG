# Project: Enterprise-RAG

## Core Value
Enterprise-RAG is a Retrieval-Augmented Generation (RAG) platform designed to efficiently manage and query an organization's internal knowledge. It combines vector search with a graph database to provide traceable and citable answers, reducing information search time and operational costs.

## Success Vision
A production-ready system where users can upload documents, query them using hybrid search (Vector + Graph), and receive accurate, cited answers with full observability of costs and performance.

## Constraints
- **Backend**: FastAPI, Qdrant (Vector), FalkorDB (Graph).
- **Frontend**: Vite, Nginx.
- **Observability**: Prometheus, Grafana, RAGAS.
- **Deployment**: Docker Compose.

## Stakeholders
- **User**: Visionary / Product Owner.
- **OpenCode**: Builder / Implementation Agent.
