## End-to-End User Flows

### 1. Document Upload → Query Flow

```
Upload Document (/upload) → Ingest (/ingest) → Embed → Store in Qdrant + Graph
                                    ↓
                            Query via /query
                                    ↓
                            Response with citations
```

**Verified:** All endpoints functional, data flows through complete pipeline.

### 2. Settings Configuration Flow

```
Settings Page → GET /settings → Load config
     ↓
User modifies settings → PUT /settings → Update config.json
     ↓
RateLimiter reads new limits → Dynamic enforcement
```

**Verified:** Settings persist, rate limits update dynamically.

### 3. Observability Flow

```
Backend Metrics → /stats/* endpoints → Redis cache
                                    ↓
                            Frontend analytics.js
                                    ↓
                            Display in Dashboard
```

**Verified:** Stats endpoints provide data, frontend displays metrics.

### 4. Quality Evaluation Flow

```
Evaluation Page → /eval/run → RAGAS metrics → Results displayed
```

**Verified:** Evaluation component triggers backend evaluation.

### 5. Chat Session Flow

```
Chat Component → /query with session_id → Response → localStorage persist
```

**Verified:** Sessions persist across browser refresh.
